## Técnicas de bordado

Durante esta práctica se realizaron diferentes puntadas de bordado siguiendo las instrucciones de la profesora. El objetivo fue aprender técnicas básicas de costura a mano y comprender cómo pueden utilizarse para decorar, unir y personalizar textiles.

### Técnicas disponibles

| Técnica | Descripción |
|---|---|
| **Hilván** | Puntada larga y simple, usada para unir temporalmente telas o como guía |
| **Punto atrás** | Puntada resistente donde la aguja entra hacia atrás del punto anterior; simula costura de máquina |
| **Cadeneta** | Serie de lazadas enlazadas que forman una cadena; decorativa y con buen contacto conductivo |
| **Pespunte** | Puntada recta de alta resistencia, usada para unir telas definitivamente |
| **Nudo francés** | Crea un punto elevado al enrollar el hilo alrededor de la aguja; ideal para texturas y detalles decorativos |

## Documentación

### Bordado

> ✏️ Durante la práctica se realizaron distintos tipos de puntadas de bordado siguiendo las demostraciones de la profesora. El objetivo fue desarrollar precisión manual, controlar la tensión del hilo y conocer diferentes técnicas de decoración textil.

**Material utilizado:**
- Hilo de bordar
- Aguja para costura
- Tela de práctica

**Proceso:**
1. Se prepararon la tela, el hilo y la aguja.
2. La profesora explicó el procedimiento de cada puntada.
3. Se practicaron diferentes técnicas de bordado sobre la tela.
4. Se ajustó la tensión del hilo para lograr puntadas uniformes.
5. Se revisaron los acabados para mejorar la precisión y limpieza del trabajo.

## Técnica de estampado

Durante esta práctica también se realizó un proceso de estampado textil utilizando moldes previamente preparados por la profesora. El objetivo fue aprender una técnica sencilla para transferir diseños decorativos a la tela mediante la aplicación de pintura textil y su posterior fijación con calor.

> ✏️ En la actividad de estampado se utilizaron moldes ya preparados. Sobre ellos se aplicó pintura textil y posteriormente se utilizó una pistola de calor para secar y fijar el diseño sobre la tela.

**Técnica:** Estampado con molde y pintura textil  

**Material utilizado:**
- Tela de práctica
- Moldes de estampado
- Pintura textil
- Brocha o esponja aplicadora
- Pistola de calor

**Proceso:**
1. Se colocó el molde sobre la superficie de la tela.
2. Se aplicó pintura textil cubriendo las áreas abiertas del diseño.
3. Se retiró cuidadosamente el molde para no deformar la figura.
4. Se dejó reposar la pintura unos minutos.
5. Se utilizó una pistola de calor para secar y fijar el estampado.
6. Se verificó que el diseño quedara uniforme y bien adherido a la tela.
