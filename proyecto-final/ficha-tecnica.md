## 2. Descripción funcional

Prenda wearable interactiva diseñada para representar emociones asociadas al inicio de una manifestación social mediante movimiento mecánico automatizado integrado en una estructura textil superior.

---

## 3. Especificaciones físicas

| Elemento | Descripción |
|---|---|
| **Estructura superior** | Aro circular con organza translúcida |
| **Materiales principales** | Organza, PVC, alambre, tela tipo cordón |
| **Tipo de prenda** | Headpiece + conjunto textil |
| **Método de uso** | Portado corporal en pasarela/performance |
| **Sistema mecánico** | Tensión textil mediante servomotores y hilos |

---

## 4. Especificaciones electrónicas

| Componente | Función | Pin |
|---|---|---|
| XIAO ESP32 S3 | Microcontrolador principal | — |
| Servo Motor 1 (rotación continua) | Movimiento de apertura | D4 |
| Servo Motor 2 (rotación continua) | Movimiento de apertura | D5 |
| Sensor táctil capacitivo | Activación del sistema | D3 |
| 2× Baterías AA | Alimentación | 5V / GND |

---

## 5. Consumo eléctrico

| Parámetro | Valor |
|---|---|
| Voltaje de operación | 5V |
| Alimentación | 2 baterías AA (3V → regulado) |
| Consumo estimado en activación | ~500–700 mA |
| Tipo de energía | Corriente directa (DC) |
