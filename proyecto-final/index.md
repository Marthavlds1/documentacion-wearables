# Proyecto Final: Wearable Diseño Avant Garde
{: .fs-8 }

**Martha Valdés · Nahomi Cruz · Annette Cunillé**  
Dispositivos Corporales | Primavera 2026 | Universidad Iberoamericana
{: .fs-5 .fw-300 }

---

## Descripción general

Este proyecto consiste en una **prenda wearable de diseño avant garde** inspirada en las emociones presentes al inicio de una manifestación social. A través de elementos textiles, estructuras mecánicas y sistemas electrónicos interactivos, la pieza busca representar visualmente la tensión emocional, la adrenalina y la liberación de expresión que emergen durante estos eventos colectivos.

La propuesta integra un sistema electrónico oculto dentro de la prenda que genera **movimiento mecánico mediante servomotores activados por un sensor táctil**, creando una interacción performática entre el usuario y la pieza.
