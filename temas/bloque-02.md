{: .fs-7 }

---

## Materiales conductivos

Los materiales conductivos permiten integrar circuitos eléctricos directamente en textiles. Los principales tipos son:

### Hilos conductores
- Hilos metálicos (plata, acero inoxidable) entretejidos con fibras textiles
- Permiten coser circuitos a mano o con máquina de coser
- Resistencia típica: 1–50 Ω/m dependiendo del material

### Tintas conductivas y resistivas
- Tintas a base de plata o carbono aplicadas mediante serigrafía o impresión
- Permiten crear trazas conductoras sobre tela o papel
- Útiles para sensores de presión y flexión

### Telas conductivas
- Tejidos metalizados (cobre, plata) para superficies amplias
- Usados en blindaje EMI, electrodos, sensores capacitivos

## Impresión 2D con tinta conductiva

Proceso para imprimir circuitos sobre textiles:

1. Diseño del circuito en software (Inkscape, Illustrator)
2. Preparación de la pantalla serigráfica
3. Aplicación de tinta conductiva
4. Curado térmico (60–120°C según fabricante)
5. Prueba de continuidad eléctrica

## Técnicas de manufactura (Tema IV)

### Bordado

El bordado manual permite integrar componentes electrónicos con hilo conductor:

| Técnica | Descripción |
|---|---|
| **Hilván** | Puntada temporal, útil para fijar componentes |
| **Punto atrás** | Puntada resistente, ideal para conexiones |
| **Cadeneta** | Decorativa y funcional, buen contacto eléctrico |
| **Pespunte** | Puntada recta de alta resistencia |
| **Nudo francés** | Para puntos de contacto y decoración |

### Serigrafía
Técnica de impresión que usa una malla tensada para transferir tinta o material conductor sobre la superficie textil.

### Corte en vinil
Uso de plóter de corte para crear diseños precisos en vinil termoadherible o conductivo.

### Impresión 3D sobre textiles
Deposición de filamento (TPU flexible, conductivo) directamente sobre tela usando impresoras FDM modificadas.

## Proceso de Diseño — Design Thinking (Tema V)

Metodología centrada en el usuario con 5 etapas:

1. **Empatizar** — Investigar al usuario y su contexto
2. **Definir** — Identificar el problema central
3. **Idear** — Generar soluciones creativas (brainstorming)
4. **Prototipar** — Construir versiones rápidas y económicas
5. **Testear** — Evaluar con usuarios reales e iterar
