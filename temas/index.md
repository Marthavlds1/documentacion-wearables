# Temas del Semestre

---

| Bloque | Tema |
|---|---|
| I | Introducción a la tecnología corporal |
| II | Textiles y materiales interactivos |
| III | Electrónica para sistemas portables |
| IV | Sensores e indicadores |
| V | Switches y actuadores |
| VI | Comunicación inalámbrica |
| VII | Desarrollo de Apps |
| VIII | Proyecto final |
